# 知行笔记 (ZhiXing Notes)

知行笔记是一款结合 AI 智能辅助的高效个人知识库管理系统。系统基于 Next.js 16 与 Python FastAPI 架构构建，支持多格式文档的 Markdown 无损转换、多模态 AI 解析、双模式文档编辑器以及游戏化的知行看板。

> “知之真切笃实处即是行，行之明觉精察处即是知。” —— 王阳明

---

## 🎯 项目说明 (Project Description)

### 核心特性

- **一键文档无损转换**：支持将 PDF、Word、Excel、PPTX 等多格式文档和 ZIP 压缩包一键解析为标准的 Markdown 文件。内置智能断行修复算法，完美还原中文语境下的段落排版。
- **AI 智能双轨制转换引擎**：
  - **⚡ 快速标准转换**：基于本地离线引擎提取纯文本，速度极快且不消耗 AI 额度。适合纯文字文档。
  - **🤖 AI 智能增强转换**：集成多模态大模型视觉识别（OCR），不仅能解析文档文字，更能理解并提取图片、复杂图表及扫描版 PDF 中的深层信息。
- **行动项自动提取 (知行合一)**：系统会自动提取笔记中的待办复选框（`- [ ]`），将其同步至全局“知行看板”，让你不仅限于记录知识，更能付诸实践。
- **双模笔记编辑器**：支持在 **富文本可视化编辑 (MDX)** 与 **纯 Markdown 源代码编辑** 之间无缝切换，兼顾所见即所得与极客写作体验。
- **流式 AI 聊天助理**：侧边栏内置随叫随到的 AI Copilot，帮你总结笔记、解答疑问或扩展思路。支持调用公共系统通道或自定义 OpenAI 兼容 API 密钥。
- **新粗野主义设计 (Neo-Brutalist)**：界面采用高对比度粗描边与明亮撞色设计，带来极高辨识度的现代 Web 交互体验。

### 技术架构

知行笔记采用全栈单体架构进行部署与接口代理：
- **前端与主服务**：基于 Next.js 16 (App Router) 提供用户界面、路由守卫与国密安全加密认证（SM2/SM4 算法）。
- **Python 解析后端**：基于 Python FastAPI 挂载 Microsoft MarkItDown 引擎与自定义断行修复算法。
- **数据库与认证**：基于 Supabase (PostgreSQL + Auth) 存储，并配置了行级安全（RLS）策略。

## 📖 使用手册 (User Manual)

### 1. 登录与安全设置
- 系统支持用户名密码登录或邮箱快捷登录。
- **数据隐私**：系统采用国密算法传输加密，结合数据库层的 RLS（行级安全防护），除了你自己，没有任何人能看到你的私人笔记。
- **AI 密钥配置**：在「设置」页面，你可以填入自己的 OpenAI 或其他兼容大模型的 API Key 与代理地址。如果不填，系统会提供每日 200 次免费基础额度的系统调用通道。

### 2. 文档解析与转换
前往 **“文档转换”** 模块，将你搜集到的资料（如书籍 PDF、会议 PPT 或一整个压缩包）拖拽上传：
- 选择 **【快速标准转换】**：如果你只需提取纯文本，不想消耗 AI 额度，且文档没有重要图片或不是扫描版，此模式能让你在几秒内得到完美的 Markdown 笔记。
- 选择 **【AI 智能增强转换】**：当遇到扫描版 PDF、大量图表或截图时，系统会调用视觉大模型帮你“看图说话”，精准还原图片内的关键信息。

### 3. 笔记管理与双模编辑
- **树状结构整理**：你可以像在操作系统中一样，无限层级地建立文件夹对笔记进行归类。
- **左侧大纲与侧边栏**：编辑笔记时，左侧可呼出悬浮的大纲视图；右侧可随时唤醒 AI 对话框。
- **双模式切换**：在编辑器顶部可一键切换模式。普通记录用富文本，精细排版切到 Markdown 源码。你还可以随时通过顶部按钮把当前笔记下载为本地 `.md` 文件。

### 4. 实践行动 (知行看板)
当你在记录笔记时，只要输入 `- [ ] 待办事项` 的 Markdown 语法：
- 这项待办会自动飞入左侧导航栏的 **“知行实践”** 看板中。
- 你可以在看板中集中管理所有散落在各个知识库中的行动项。
- 只有当你把理论转化为实际行动，并在看板中勾选完成时，你才是真正的做到了“知行合一”。

## 🛠️ 开发者部署指南

如果你是开发者，希望将本项目部署至自己的服务器或 Vercel，请参考以下步骤：

### 1. 配置环境变量
在项目根目录下创建 `.env.local` 文件：
```env
NEXT_PUBLIC_SUPABASE_URL=你的Supabase项目地址
NEXT_PUBLIC_SUPABASE_ANON_KEY=你的Supabase公钥
SM2_PRIVATE_KEY=你的国密解密私钥
SYSTEM_OPENAI_API_KEY=公共通道大模型密钥
SYSTEM_OPENAI_BASE_URL=公共通道代理地址
SYSTEM_OPENAI_MODEL=mimo-v2.5
```

### 2. 本地启动
```bash
# 1. 激活 Python 虚拟环境并安装依赖
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. 安装前端依赖并启动双端并发服务
npm install
npm run dev
```

### 3. Vercel 一键部署
项目已适配 Vercel 全栈单体服务架构：
- 部署时，Vercel 会自动读取 `package.json` 构建前端。
- 同时通过 `vercel.json` 捕捉 `/api/py/*` 路由，并触发基于 `requirements.txt` 的 Serverless Python 后端函数构建。
